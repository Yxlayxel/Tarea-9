Colores Multinavegador

Hay ms de 160 colores con nombre, que son compatibles con la mayoria de los navegadores modernos, estos nombres se pueden usar directamente en css sin especificar valores de algun modelo de color.

    Por ejemplo

  • Blanco
  • Negro
  • Salmon
  • Azul
  • Verde

Borde

Para que a un elemento HTML se le aplique color a su borde, se necesitan 3 propiedades: border-style, border-color, border-width
